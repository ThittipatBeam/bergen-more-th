Hello Loay,Thank you for providing API access. We used it to evaluate Cohere embedding, reranking, and generation models on two Thai RAG benchmarks. The attached HTML contains the full methodology and interactive leaderboards.

Why we built this evaluation

Our pipeline follows BERGEN, a benchmarking library for retrieval-augmented generation. When we reviewed the available Thai evaluation data, we found that many questions lacked reliable Thai ground-truth coverage. We therefore built two evaluation tracks while keeping BERGEN’s RAG methodology.

Datasets and code

  • siamaids/thai-wiki-qa-v1 — Thai Wikipedia QA
  • VISAI-AI/nitibench-plus — Thai legal cases and law
  • ThittipatBeam/bergen-more-th — pipeline code

What management should take forward

Shortlist Cohere retrieval for a controlled follow-up and keep generator selection open. Command A did not lead Overall, even though it appeared in the leading Match TH pipeline. Next, test real company documents, direct retrieval quality, per-request latency, and cost per 1,000 queries against self-hosted alternatives.

Generation timing needs a controlled testMedian generation passes: Command A 141.4 min, Plus 91.9, DeepSeek 9.0. These are whole-pass harness observations, not per-request API latency.
