Which Thai RAG system reads best? The judge says so. ระบบ RAG ภาษาไทยตัวไหนอ่านดีที่สุด? ผู้ตัดสินเป็นคนบอก

Every system is ranked by its judge score — an LLM grading factual correctness against the retrieved Thai context. String metrics alone under-credit Thai answers: a different transliteration of the same entity, or a correct refusal like ไม่พบข้อมูล, looks like a failure to a string match. Here the judged truth leads the first column, and the strings support beside it. ทุกระบบถูกจัดอันดับด้วยคะแนนผู้ตัดสิน — LLM ที่ให้คะแนนความถูกต้องเทียบกับบริบทภาษาไทยที่ดึงมา ตัวชี้วัดแบบเทียบข้อความล้วนประเมินคำตอบภาษาไทยต่ำเกินไป การสะกดถ่ายเสียงต่างกันของชื่อเดียวกัน หรือการปฏิเสธที่ถูกต้องอย่าง ไม่พบข้อมูล อาจถูกมองว่าผิดเพียงเพราะไม่ตรงตัวอักษร ที่นี่คะแนนจากผู้ตัดสินนำคอลัมน์แรก และตัวชี้วัดข้อความเป็นเพียงเสริมข้างๆ

A Thai-focused fork of BERGEN, a benchmarking library for retrieval-augmented generation. Thai-aware metrics, an LLM-as-judge, and API-based pipelines. โครงการแยกของ BERGEN ที่เน้นภาษาไทย — ไลบรารีสำหรับวัดประสิทธิภาพ retrieval-augmented generation ตัวชี้วัดที่เข้าใจภาษาไทย ผู้ตัดสินแบบ LLM และไปป์ไลน์ผ่าน API
